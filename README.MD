# Paradise Nursery Shopping Application

Paradise Nursery is a dynamic React e-commerce web application designed for plant lovers. Users can browse categorized houseplants, add items to their shopping cart, manage item quantities, and view live updates on total costs and item counts powered by Redux Toolkit.

## Features
- **Landing Page**: Visually engaging landing page with background imagery and quick navigation.
- **About Us**: Information about Paradise Nursery's mission and passion for plants.
- **Product Listing**: Categorized selection of plants with live "Add to Cart" toggles and real-time total cart count.
- **Shopping Cart**: Full cart management including quantity increments, decrements, item deletion, subtotal calculation, and checkout alerts.
